BoxNow Label Fetcher - Българска версия
=========================================

Това е обновената версия на приложението за изтегляне на етикети от BoxNow API.

Основни подобрения:
- Полна българска локализация
- Работи с новия API (без count параметър)
- Скриване на полетата за вход след успешна автентификация
- Поддържа само A4 и A6 формати за етикети

Как да използвате приложението:
1. Стартирайте BoxNowAllLabelsV8.exe
2. Въведете вашите Клиент ID и Клиент Secret
3. Натиснете "Вход" за автентификация
4. След успешна автентификация изберете:
   - "Етикет за една пратка" - за избор на конкретни пратки
   - "Етикети за всички пратки" - за всички нови пратки
5. Изберете формат на хартията (A4 или A6) и колко етикета на лист
6. Натиснете "Потвърди и изтегли"

Файловете се записват в папки:
- "new" - за всички етикети
- "new_single" - за избрани етикети

За подробни инструкции вижте instructions_boxnow_app.pdf

Файлове в пакета:
- BoxNowAllLabelsV8.exe - Главното приложение
- BoxNow.png - Логото на приложението
- instructions_boxnow_app.pdf - Подробни инструкции
- README.txt - Този файл с инструкции
- src/ - Папка с изходния код за разработчици
